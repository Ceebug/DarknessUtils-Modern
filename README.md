 # DarknessUtils Modern

An updated fork of [@DersWasTaken](https://github.com/derswastaken)'s [DarknessUtils](https://modrinth.com/mod/DarknessUtils) mod, targeting modern [Minecraft](https://minecraft.net) ([26.3+](https://www.minecraft.net/en-us/article/minecraft-26-3-release-candidate-3)), with patches, and support for newer bosses.

> [!NOTE]
> This project is developed with help from AI, (Specifically [GPT-6](https://en.wikipedia.org/wiki/GPT-6) on the [ChatGPT website](https://chatgpt.com) using the [ChatGPT Codex Connector](https://github.com/apps/chatgpt-codex-connector) with the code reviewed throughout development.
